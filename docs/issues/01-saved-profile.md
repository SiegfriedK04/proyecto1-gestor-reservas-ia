## Historia

Como usuario recurrente, quiero reutilizar mis datos de contacto y preferencias de reserva para completar el proceso más rápidamente.

## Alcance

- Perfil asociado al usuario.
- Nombre, teléfono y preferencias no sensibles.
- Precarga de datos durante una reserva.
- No almacenar número completo de tarjeta ni CVV.

## Criterios de aceptación

- [ ] El usuario autenticado puede crear y actualizar su perfil.
- [ ] El formulario de reserva reutiliza los datos guardados.
- [ ] Otro usuario no puede consultar ni modificar el perfil.
- [ ] Existen pruebas de modelo, vista y permisos.
